# ✅ Mini Todo Manager

A simple and user-friendly **Todo Manager** built with **React** and **Vite**.

This project allows users to create, manage, and organize their daily tasks through a clean and intuitive interface.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 View and manage your todo list
- 🎨 Clean and simple user interface
- 📱 Responsive design
- ⚡ Fast development with Vite

## 🛠️ Technologies

- **React**
- **JavaScript**
- **Vite**
- **CSS**
- **ESLint**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/samanyarzada/Mini-Todo-Manager.git
```

### 2. Navigate to the project directory

```bash
cd Mini-Todo-Manager
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.
